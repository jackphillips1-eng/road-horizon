# Road Horizon — Live Map Update

This is a static GitHub Pages PWA. It adds a Leaflet/OpenStreetMap map, live GPS marker and accuracy circle while keeping local journey tracking and Bordon road completion.

## Upload to GitHub

1. Open the `road-horizon` repository on GitHub.
2. Choose **Add file → Upload files**.
3. Upload every file from this folder into the repository root, replacing files with the same names.
4. Commit the changes to `main`.
5. Wait a minute or two for GitHub Pages to redeploy.
6. Fully close and reopen the home-screen app. If the old version remains, remove it from the home screen, visit the Pages URL in Safari, then use **Share → Add to Home Screen** again.

Location requires HTTPS, which GitHub Pages provides. Choose **Allow While Using App** when prompted. Road data and map tiles require a connection the first time; previously viewed resources are cached where the browser permits.

OpenStreetMap data and tiles are credited in the map, as required.
